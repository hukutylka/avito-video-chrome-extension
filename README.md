# Avito Video Saver 1.2 — звук и название объявления

## Установка
1. Установите FFmpeg для Windows, добавьте папку `bin` в PATH. Проверьте `ffmpeg -version` и `ffprobe -version`.
2. Распакуйте архив.
3. Запустите `helper\\start_windows.bat` и оставьте окно открытым.
4. Откройте `browser://extensions/`, удалите старую версию расширения.
5. Нажмите «Загрузить распакованное расширение» и выберите папку `extension` (в ней `manifest.json`).
6. Обновите объявление Ctrl+F5, запустите видео и нажмите «Скачать видео со звуком».

Готовый MP4 сохраняется в `helper/downloads/` с заголовком объявления и временем скачивания.

## Звук
Расширение собирает доступные HTTPS-ссылки. Локальный FFmpeg пробует HLS/DASH и прямые источники, объединяет доступные аудио- и видеодорожки. FFprobe проверяет наличие обеих дорожек; без звука успех не показывается.

Если Avito отдаёт только немой MP4, blob, DRM/шифрованный или недоступный FFmpeg поток, звук таким способом получить нельзя. CAPTCHA, DRM, авторизация и антибот-защита не обходятся. Cookies браузера не экспортируются. Ссылки и название передаются только локальному помощнику на 127.0.0.1.
